# Контрольная работа №3 (практики 13-18)

В папке реализовано единое приложение "Заметки" с:
- Service Worker и офлайн-режимом;
- Web App Manifest и иконками для установки PWA;
- архитектурой App Shell (динамическая подгрузка `content/*`);
- WebSocket-уведомлениями (Socket.IO);
- push-уведомлениями и отложенными напоминаниями (snooze на 5 минут).

## Запуск

1. Установить зависимости:
   - `npm install`
2. Один раз подготовить локальный HTTPS-сертификат:
   - `npm run https:setup`
3. Запустить сервер:
   - `npm start`
4. Открыть в браузере адрес, который сервер выведет в консоль.

### HTTPS (для практики №15)

После `npm run https:setup` в папке проекта создаются `localhost.pfx`, `localhost.cer` и доверенный сертификат для `localhost`. Если порт `3001` занят, сервер автоматически попробует `3002`, `3003` и так далее.
